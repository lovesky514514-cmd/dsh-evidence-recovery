- **运行时代码已有实质改动：** `index.js` 增加无效规则的 logger 警告，`ledger.js` 增加只读待处理清单、记录检查和对账预览；离线管理端 `admin.js` 增加 `list --pending`、`inspect --record-id`、`reconcile --dry-run` 与 `--expect-preview`。`demo.js` 和 `cordis.patch.yml` 仅换行格式变化。

- R30 兼容组合仍 BLOCKED；R16 运行时磁盘结算失败注入未验证；macOS/Linux、多进程/跨机、真实下游和强制断电未验证。详见 [问题与修复记录](../问题与修复记录.md)。

## 首次公开发布说明 — 0.1.1

**版本：`0.1.1`** · **许可证：Apache-2.0** · **状态：公开 Beta 首发源码（Release 标签待创建）**

这是 SKY Evidence Recovery 的**第一个公开版本**。此前内部构建号仅用于开发/验收记录，不是已公开发行的版本历史。本段仅描述当时 **`0.1.1` 首次公开发行**与内部候选 `0.1.4-beta.1` 的关系：当时只调整了版本元数据及文档；**不适用于本次 `0.1.2`**，因为本次确实修改了运行时代码。

## 能做什么

- 对显式配置的 DSH 副作用工具，在派发前持久写入身份与参数指纹。
- 首次明确成功后阻止重复提交；结果不确定、取消、超时、响应丢失后保留 `unknown`，不盲目重试。
- 账本锁丢失、被篡改或不可用时拒绝受保护调用；健康工具可查看实际保护状态。
- 只允许隔离的管理员在独立回读后离线对账；工具返回错误码不作为解除保护的可信证据。

## 安全边界

只保护 `rules` 明确列出的工具；默认 `rules: []` 没有保护。当前实证范围仅 Windows、单进程、模拟下游。插件完全没加载时不能自行保护；没有隔离权限的 Agent 可篡改账本。不支持跨主机/多进程共享，不承诺 exactly-once。macOS/Linux、真实业务下游和断电恢复均未测试。

未经额外验证，不应把本插件宣传为生产级事务或支付安全系统。许可证详见根目录 `LICENSE`。
